## 复现步骤

zlib：
```
cmake -S D:/tools/downloads/zlib-develop -B D:/tools/build-zlib -G Ninja \
  -DCMAKE_C_COMPILER=D:/tools/mingw64/bin/gcc.exe -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX=D:/tools/zlib -DBUILD_SHARED_LIBS=OFF
cmake --build D:/tools/build-zlib && cmake --install D:/tools/build-zlib
```

TSK 4.15.0（autotools，必须加 `--disable-dependency-tracking` + `MAKE=mingw32-make`，否则 config.status 因缺 `make` 失败）：
```
./configure --prefix=D:/tools/tsk-4.15.0-ucrt64 --disable-shared --enable-static \
  --disable-dependency-tracking --disable-java --disable-cppunit \
  --without-afflib --without-libewf --without-libbfio --without-libvhdi --without-libvmdk --without-libvslvm \
  CPPFLAGS=-ID:/tools/zlib/include LDFLAGS=-LD:/tools/zlib/lib MAKE=mingw32-make
mingw32-make -C tsk -j8
```
之后把头文件（71 个，含生成的 `tsk_config.h`）按相对路径拷到 `include/tsk/`，`.libs/libtsk.a` 拷到 `lib/libtsk.a`。

uife 配置（TSK 版）：
```
cmake -S . -B build-local-tsk -G Ninja -DCMAKE_MAKE_PROGRAM=D:/tools/ninja/ninja.exe \
  -DCMAKE_CXX_COMPILER=D:/tools/mingw64/bin/g++.exe -DCMAKE_BUILD_TYPE=Release \
  -DZLIB_INCLUDE_DIR=D:/tools/zlib/include -DZLIB_LIBRARY=D:/tools/zlib/lib/libzs.a \
  -DLIBTSK_INCLUDE_DIR=D:/tools/tsk-4.15.0-ucrt64/include \
  -DLIBTSK_LIBRARY=D:/tools/tsk-4.15.0-ucrt64/lib/libtsk.a
```

## CLI 产品化（2026-11-04 完成并验证）

`src/cli/main.cpp` 重写（454 → ~800 行），README「CLI」章节与 PRD 第 5 节已同步：

- **退出码表**：0 成功 / 1 运行时错误 / 2 用法错误（invalid_argument、out_of_range、未知命令/缺参数）/ 3 镜像驱动未接入 / 4 文件系统解析器缺失。`CliError : std::runtime_error` 携带 exit_code，`mount_filesystem` 的解析器缺失错误与 `info` 的驱动缺失错误已改抛 CliError；顶层 catch 按 CliError→invalid_argument/out_of_range→exception 顺序映射。错误消息现在会附上实际已启用的解析器列表（修掉了原来写死"NTFS 与 ext2/3/4"的过时文案）。
- **`--json` 全局选项**：在参数解析前剥离；info/list/extract/restore 均输出单行 JSON 对象（json_escape 处理引号/控制字符，UTF-8 直通）；JSON 模式错误输出 `{"error":{"code":N,"message":"..."}}` 到 stdout；extract 的进度条（stderr）在 JSON 模式关闭以保证输出纯净。
- **`--manifest <file>`**（extract/restore）：导出后写 `<sha256>  <path>` 行（sha256sum -c 兼容）。
- **`batch <清单文件>`**：每行一条完整命令（省略 uife 前缀，内部补占位 token）；空行/# 注释跳过；支持双引号 token；失败不中断，全部跑完后退出码 0 或 1；JSON 模式输出 JSONL（`{"line":N,"command":...,"status":"ok","result":{...}}` / error 形态）；行内可写 `--help`。支持 UTF-8 BOM。
- **测试**：`tests/cli_argument_tests.cmake` 追加了退出码断言（2/0）、JSON 错误对象断言、batch JSONL/人类模式汇总断言。`uife info`（缺镜像参数）从"打印用法退出 0"改为退出码 2（行为变更，已在帮助中体现）。
- **验证**：build-local 与 build-local-full 均 4/4 通过；手工端到端用 Python 手工构造的最小 ISO fixture（`D:/tmp/cli_test.iso`，HELLO.TXT="fixture-data"）验证了 list/extract/--manifest/JSON/batch 全链路。
